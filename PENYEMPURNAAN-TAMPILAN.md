# Penyempurnaan Tampilan Website Akademi Futsal

## Perubahan
- Identitas oranye dan logo asli dipertahankan, dengan palet gelap yang lebih seragam.
- Navbar publik diperhalus; menu seluler otomatis ditutup setelah berpindah halaman, serta ditambahkan label aksesibilitas.
- Beranda: tipografi, kartu program, bagian langkah bergabung, dan ajakan pendaftaran baru.
- Footer: navigasi halaman dan akses portal yang lebih lengkap.
- Portal pemain, pelatih, dan owner: sidebar, active state, topbar, cards, KPI, dan form lebih konsisten.
- Perbaikan tampilan mobile, fokus keyboard, dan pengurangan animasi untuk preferensi aksesibilitas.

## Menjalankan
```bash
npm install
npm run dev
```
Untuk uji build: `npm run build`.

## Catatan penting
- Semua halaman/routing, logo, autentikasi, serta fungsi database demo dipertahankan.
- Angka prestasi dan profil akademi dalam data contoh harus diverifikasi sebelum dipublikasikan.
- Penyempurnaan ini adalah frontend; portal dalam mode demo masih memakai localStorage, bukan database produksi.
