# Pembaruan UI putih–oranye

- Website publik: latar putih hangat dan aksen oranye.
- Pilihan portal login: hanya simbol dan nama peran (Pemain, Owner, Pelatih); tautan tetap sama.
- Portal tiga peran: sidebar putih, menu tanpa underline, active state oranye muda, topbar dan kartu modern.
- Layout responsif untuk desktop/tablet/ponsel.
- Logika autentikasi, data, dan routing tidak diubah.

Jalankan `npm install` lalu `npm run dev`. Untuk verifikasi produksi, jalankan `npm run build`.
